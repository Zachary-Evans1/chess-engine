# chess-engine
A chess engine built in C++ with an AI opponent

Stage 1 — Board representation (complete)

Represent the board in code
Place pieces
Print the board to the terminal

Stage 2 — Move generation

Generate legal moves for each piece
Handle special moves (castling, en passant, promotion)

Stage 3 — Game loop

Two players can play against each other in the terminal
Check/checkmate detection

Stage 4 — AI opponent

Minimax algorithm
Basic move evaluation
Alpha-beta pruning to make it faster
